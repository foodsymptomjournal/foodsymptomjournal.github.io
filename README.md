# G.I. Journal support site

This folder contains the public support and privacy website for **G.I. Journal**.

The site is currently hosted from the GitHub Pages user-site repository:

`foodsymptomjournal/foodsymptomjournal.github.io`

The existing URL can remain unchanged even though the app is now named G.I. Journal.

## Publish this update

1. Open the repository on GitHub.
2. Replace these files at the repository root:
   - `index.html`
   - `privacy_policy.html`
   - `og.png`
   - `README.md`
3. Commit the changes to the `main` branch.
4. GitHub Pages will republish automatically if Pages is still configured for `main` and `/(root)`.
5. Verify:
   - Support: https://foodsymptomjournal.github.io/
   - Privacy: https://foodsymptomjournal.github.io/privacy_policy.html

These URLs can continue to be used as the App Store Support URL and Privacy Policy URL.
